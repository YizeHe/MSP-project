Message Security Protocol

A censorship-resistant, end-to-end encrypted messaging prototype. The public chain tracks MST economics and burn proofs only; message bodies travel exclusively over a DTN / UDP P2P mesh. Signaling seeds help with discovery and hole punch—not chat relay.

Read the guide View on GitHub

What is MSP?

MSP (Message Security Protocol / MST Network) separates three concerns that many networks mix together:

  • DTN / P2P mesh — encrypted chat, flood, store-carry-forward, burn-after-read.
  • Public chain — claim, transfer, burn hashes, register, coinbase from a pre-allocated miner pool (no inflation beyond genesis allocation).
  • Signaling — Cloudflare Worker or local msp-seed for peer discovery and NAT hole punch only.

Tokenomics

Total supply 4,226,880 MST. Free claim: 128 MST × 210 nodes. Miner pool: 4,200,000 MST.

Privacy-minded send

Seal once, burn via a one-time burner address, attach a miner-signed BurnTicket, then send over DTN.

Lab-friendly

Mainnet msp-mainnet-1 is live in code. Version 1.4.0-mainnet. See MAINNET.md.

Get started

git clone https://github.com/YizeHe/MSP-project.git
cd MSP-project
git checkout dev

go build -o bin/msp ./cmd/msp
go build -o bin/msp-seed ./cmd/msp-seed

./bin/msp -c init
./bin/msp -c start

Windows users can build bin/msp.exe the same way. See bin/README.md for local binary layout (executables are not committed).
